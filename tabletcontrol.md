Зі сторони планшету вимагається:

F-droid це магазин відкритого програмного забезпечення, з якого завантажено більшість компонентів для мого проєкту

Tailscale - захищена віртуальна приватна мережа на базі протоколу WireGuard, що об'єднує пристрої в єдину зашифровану локальну мережу через інтернет, оминаючи NAT і фаєрволи, без потреби у публічній («білій») IP-адресі чи прокиданні портів.Завантажено з F-droid (надалі - F)

Termux - емулятор термінала та ізольоване Linux-середовище для Android, який дозволяє виконувати консольні команди Linux, встановлювати пакети (Python, Git) та запускати скрипти й сервери безпосередньо на мобільному пристрої. F

Python3 - мова програмування

Flask - бібліотека мови Python для розробки вебзастосунків та REST API, забезпечує обробку HTTP-запитів, створює вебпанель керування та пов'язує графічний вебінтерфейс із системними командами ОС. termux: pkg install flask -y

Shizuku та rish - сервіси доступу до системних API Android через бездротове налагодження (Wireless Debugging). `rish` — його консольна оболонка, встановлена у термукс. Повністю замінює ADB. Дозволяє локальним додаткам (Termux) виконувати привілейовані системні команди без ПК, без постійного мережевого портів і без повного рутування

droidVNC-NG - VNC-сервер для Android.
Веде трансляцію екрану, кодує її й передає віддаленому клієнту (У даному випадку - MultiVNC) за протоколом RFB, забезпечуючи віддалений перегляд із низькою затримкою.
